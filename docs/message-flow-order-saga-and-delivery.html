Сага (до CONFIRMED)

sequenceDiagram
    participant GW as Gateway
    participant O as Order
    participant I as Inventory
    participant P as Payment
    participant K as Kafka

    GW->>O: POST /order
    O->>O: CREATED
    O->>K: OrderCreated
    O->>K: Reserve (команда)
    K->>I: reserve
    I->>I: выбрать склады, резерв
    I->>K: InventoryReserved
    O->>K: Charge
    K->>P: списать
    P->>K: PaymentCompleted
    O->>O: CONFIRMED
    O->>K: OrderConfirmed + allocations

Доставка (после CONFIRMED)

sequenceDiagram
    participant K as Kafka
    participant D as Delivery
    participant C as Carrier
    participant O as Order

    K->>D: OrderConfirmed
    D->>D: 1 allocation = 1 отгрузка NEW
    D->>K: забронировать перевозку
    K->>C: booking
    C->>K: tracking_number
    D->>D: READY_TO_SHIP
    Note over D: кнопка / мок отправили
    D->>D: SHIPPED
    C->>K: чекпоинты
    D->>D: DELIVERED
    D->>K: delivery-events: доставка завершена
    K->>O: доставка завершена
    O->>O: COMPLETED
